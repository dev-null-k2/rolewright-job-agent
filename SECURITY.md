# Security policy

Rolewright runs entirely inside the user's own Claude account and reads Gmail read-only. It has no server of its own.

If you find a way it could send mail, leak a user's resume or profile, run untrusted content as instructions, or
reach a site it should not, please report it privately through
[GitHub's private vulnerability reporting](https://github.com/dev-null-k2/rolewright-job-agent/security/advisories/new)
rather than a public issue. You will get a reply within a week.
